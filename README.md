# На одной волне

Telegram-бот для независимого прохождения опросника двумя партнёрами и сравнения ответов.

## Railway
Создайте сервис из репозитория, задайте секрет BOT_TOKEN (токен от @BotFather), подключите volume /data. Бот работает через polling; публичный домен не требуется.

## Команды
/start — создать пару или присоединиться по ссылке
/continue — продолжить
/status — прогресс и ссылка

В MVP 26 вопросов. Процент — доля одинаковых вариантов, а не психологическая диагностика.
